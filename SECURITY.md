# Security boundary

This repository contains no working cryptographic protocol. The byte/integer example provides representation and round-trip behavior only. Do not use it to encrypt, anonymize, authenticate, erase or share secrets. The historical design has not been proven reversible or secure.

Do not include private data in issues or test cases. For a vulnerability in the example or documentation, use GitHub private vulnerability reporting if available, or contact the maintainer through a private channel on their GitHub profile. Include a minimal synthetic reproduction and affected commit.
